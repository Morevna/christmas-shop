# Christmas Shop 🎄🎁

An interactive holiday web application featuring a functional gift catalog. Built from scratch with modular vanilla JavaScript, focusing on fluid state transitions, dynamic data parsing, and user-centric UI components.

🔗 **[Live Demo](https://morevna.github.io/christmas-shop/)**

---

## 🛠️ Tech Stack & Architecture

- **Core Engine:** Vanilla JavaScript (ES6+), native DOM manipulation.
- **Data Layer:** Asynchronous integration of product schemas and superpowers using JSON objects.
- **Styling & Layout:** Fluid responsive architecture optimized for desktop, tablet, and mobile views (<768px).

---

## 🚀 Key Technical Features

- **Stateful Navigation & Scroll Control:** Engineered a responsive burger menu with built-in scroll blocking architecture (`overflow: hidden`) that cleanly toggles document states when menus or overlays are active.
- **Interactive UI Utilities:** Developed an autonomous "Back to Top" navigation engine triggered upon passing 300px thresholds, complete with optimized window-scroll event handlers.
- **Dynamic Content Modals:** Implemented an extensible product presentation system. Interacting with catalog item nodes maps rich object parameters (such as `superpowers` levels and descriptions) directly onto reusable markup templates.
- **Micro-interactions:** Configured precise focus, visibility, and pointer-state transformations across transitions to maintain predictable layout layout flows.
